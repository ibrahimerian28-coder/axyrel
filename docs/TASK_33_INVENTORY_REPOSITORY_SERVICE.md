# Task 33 — Inventory Repository / Service

Introduces the PostgreSQL repository and application service foundation for `InventoryItem`.

## Included
- Tenant-scoped get/list/create/update/soft-delete repository operations.
- Search by item name and status filtering.
- Application service delegating inventory operations to the repository.

## Not included
- Inventory transactions (Task 34).
- Technician stock (Task 35).
- Inventory business rules (Task 36).
- Production API endpoints or UI integration.
